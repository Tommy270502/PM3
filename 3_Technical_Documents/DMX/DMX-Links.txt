In the above AppNote a solution with an additional pin and a resistor for generating the BREAK is suggested.
However, it is also possible to temporarily reconfigure the TX output as a normal GPIO output and set it to low for 100us and then configure it back to the alternate function as UART-TX.
MAB (Make After Break) can easily be generated as normal GPIO output set to high or by waiting 12us before transmitting.
